# 3D Gaussian Splatting

This is a personal project to explore and better understand **3D Gaussian Splatting**.

The goal is to reconstruct a mug in 3D from photographs using the official [INRIA implementation](https://github.com/graphdeco-inria/gaussian-splatting).

## Project Steps

- **COLMAP:** Initial 3D reconstruction using 67 photographs.
- **Training:** Training the Gaussian Splatting model for 3,000 iterations.
- **Rendering:** Generating images from the trained model.

The different steps were carried out using Google Colab notebooks.

## Note

This project was mainly done for learning and experimentation. The algorithm was not implemented from scratch.

**AI tools were used extensively** to save time.
